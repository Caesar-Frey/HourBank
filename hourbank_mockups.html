Principles
  1. Hairlines, not shadows. 1px borders carry the structure.
  2. Numerals are sacred. Always monospaced for the ledger to feel earned.
  3. Italic is emphasis. Don't bold things — italicise them in serif.
  4. Status by colour, not iconography. Three-tone traffic system: moss / amber / crimson.
  5. Dark mode equals "in flight." Active sessions invert the palette to signal focus.

Prompt for Claude Design / Cursor / v0

Design a mobile app called HourBank for a private high school tutor running
a prepaid-credits business. The app is the tutor's tool to manage student
balances, run sessions, and send sign-off receipts to parents.

AESTHETIC DIRECTION — strict, hold the line:
- "Editorial ledger" — borrows from boutique fintech (Mercury, Monzo) and
  Penguin Modern Classics typography. Not playful, not cartoonish, not
  generic edtech.
- Warm cream paper background (#F4EFE6), NOT white. Subtle paper grain.
- Deep warm ink as primary text (#1B1714).
- Single accent: oxblood (#7A2530). Use sparingly — italic emphasis,
  primary CTAs, balance highlights.
- Status palette: moss green #3F5641, amber #B8743F, crimson #9A2A2A.
- Hairline borders (1px, #D9CFBF) instead of drop shadows. No shadows
  except on elevated phone frames in marketing views.

TYPOGRAPHY:
- Display: Fraunces (variable serif, Google Fonts). Use opsz 144 and SOFT
  60–100 for italics. Light weights only (300–400).
- Body: Geist (Google Fonts).
- Numerals: Geist Mono (Google Fonts) — used for ALL balances, durations,
  timestamps, prices. This is non-negotiable; numerals are the soul of
  this product.
- Italic in Fraunces is the only emphasis. Do NOT use bold for emphasis.

LAYOUT PRINCIPLES:
- Generous vertical rhythm. Don't cram.
- Section labels are tiny uppercase Geist Mono with letter-spacing 0.12em
  in muted ink.
- Active session screen INVERTS the palette to dark — ink background,
  cream text — to signal "in flight."

SCREENS to design (mobile, iPhone 14/15 viewport):
1. Roster (home) — list of student cards with colour-coded balance
   pills (moss/amber/crimson), summary stats above, bottom tab bar.
2. Student detail — name as a serif display headline, prominent boxed
   balance hero with double-border framing (think old certificate),
   ledger list styled like a bank statement.
3. Live Session — DARK theme, big circular elapsed timer, topic chips
   the tutor taps during the lesson, pause + end session controls.
4. End Session review — receipt-style summary with monospaced metric
   rows, required topic chips, parent notes textarea, save & send CTA.
5. Top-Up — package tier cards (5 / 10 / 15 / custom hrs) with a
   pre-selected "best value" tier, payment method + reference inputs,
   confirm CTA showing total.

CRITICAL RULES:
- Never use generic blue or teal. Never use rounded "friendly"
  illustrations. Never use stock education iconography (graduation caps,
  pencils, books).
- Never use Inter, Roboto, Poppins, or any default system font.
- Numerals MUST be monospaced. Always.
- Italic serif for emphasis. Never use bold for emphasis.
- South African context — Rand prices (R 5,500), CAPS / IEB / Cambridge
  curriculum tags, EFT as default payment method.

Build with React Native + Expo + NativeWind. Use Expo's Google Fonts
package for Fraunces, Geist, and Geist Mono. Output a single Expo
project with all five screens navigable.
